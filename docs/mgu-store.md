# MGU Store: original v0.1.5 stable source

This repository's **main branch** advertises `ethanol_mix@0.1.5` through `mgu-repo.json`.
The on-device builder **does not recompile** the app. It repacks the original
v0.1.5 OAP file tree (including the real HMI XML and graphics resources) with
byte-verified file checksums. It excludes the proprietary BMW `oap-sdk` module;
the Store obtains an SDK module from a donor already installed on the user's car.

## Add the source (car owner)

1. Park with stable power. Use a supported, user-authorized iDrive 7 MGU with MGU Store and its internet uplink.
2. In the Store use Settings -> Add source, `HasMan/turnkey-ethanol-blend`, **Branches -> main**.
3. Refresh. Confirm `TurnKey E Blend`, **version 0.1.5**, and the latest commit.
4. If you already have another `ethanol_mix` installed, back up settings before any downgrade. The Store may not offer a lower-version update; removing only the broken `ethanol_mix` may be necessary to install v0.1.5. Do not touch other apps or MGU firmware.
5. Install, then validate screens and buttons **while parked** before trusting any readings.

## Alternative: GitHub release

For owners using the Store's **Releases** channel, upload the SDK-free
`ethanol_mix@0.1.5.tgz` generated by this repository as an ordinary public
GitHub Release asset (tag `v0.1.5`). Do NOT upload the original `.mgu` because
it embeds proprietary BMW SDK content. Releases and branch channels are separate.

## Compatibility

v0.1.5 previously worked when installed manually on one 2023 X3 M Competition.
The Store install path **has not yet been verified** end-to-end; identical
app files are a strong rollback measure but do not guarantee another head unit's
SDK, renderer or DME behaves the same. DME memory address `0xB00060D2` is
specific to the tested calibration. Verify sensor readings independently before
using them to decide real fuel quantities.

Public source remains in `apps/ethanol_mix/`; `store-v015/package/` is the
frozen SDK-free *generated output tree* from the original working `.mgu` so the
Store does not silently replace its UI with a new build. All source and generated
assets in this repository must comply with the original authors' licenses.
